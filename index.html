Diese App liest todos.json aus dem privaten Repo sanamor-todos. Dafür brauchst du einmalig ein GitHub-Token mit Lesezugriff. Es wird nur in diesem Browser gespeichert (localStorage), nicht irgendwo hochgeladen.


Token erstellen: github.com → Settings → Developer settings → Personal access tokens → Fine-grained token → Zugriff nur auf Repo "sanamor-todos" → Permission "Contents: Read-only".
